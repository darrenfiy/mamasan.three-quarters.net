# mamasan.three-quarters.net

宇宙媽媽賞｜輕贏實驗室的官方網站。純靜態站，由 GitHub Pages 提供服務。

治理正本：`Control-Room/PM/DECISIONS/2026-09-08-mamasan-brand-site-home.md`。
內容來源：`mamasan-lab/`（`0-manifesto/`、`1-podcast/`、`3-cometime/`、`自我介紹.md`、`品牌標語.md`）。

## 定位

這個站是四分之三國際「AI 品牌營運」的旗艦案例，不是獨立品牌站。
「掛在四分之三底下」由**網域**表達，不由檔案位置表達 —— 所以內容在這個獨立 repo，
不在 `darrenfiy.github.io` 裡面。日後若要獨立：fork ＋ 改一筆 DNS，內容一個字都不用動。

靜態站沒有登入、Git 歷史不可刪除。後台走 Notion 或同類工具，由她自己保管。
理由見決策文件第 4 節。

## 樣式

單一 `assets/css/styles.css`，無 build、無相依套件、無 JavaScript。

視覺上刻意與 `three-quarters.net` 同一家族（紙感米色、襯線字、圓角面板），
但主色從公司的赭紅換成她自己定的**乾燥玫瑰 × 香檳金 × 墨綠** ——
看得出同一家出品，但是她的聲音。

## 部署

1. GitHub repo → Settings → Pages → Source 選 `main` / root。
2. DNS 加一筆 `CNAME`：`mamasan` → `<owner>.github.io`。
3. `CNAME` 檔已經在 repo 裡，內容是 `mamasan.three-quarters.net`。
4. Pages 設定頁勾 Enforce HTTPS（憑證簽發需要幾分鐘）。

`.nojekyll` 已加，避免 Jekyll 處理底線開頭的路徑。
